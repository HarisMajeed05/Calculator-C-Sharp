# Scientific Calculator

A scientific calculator built with C# and Windows Forms (.NET Framework 4.7.2).

## Features

- Digits, `+`, `-`, `*`, `/`
- Remainder (`mod`), sign change, backspace and clear
- Square, square root, power and reciprocal
- Factorial
- `sin`, `cos`, `tan`
- `log` and natural log
- `Ans` button to reuse the last result

## Run

1. Open `bscs22017_SciCal.sln` in Visual Studio.
2. Press F5.

## Files

- `MyCal.cs`: calculator logic
- `MyCal.Designer.cs`: form layout
